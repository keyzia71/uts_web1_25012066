## Deskripsi
Aplikasi ini digunakan untuk menampilkan menu kantin,
melakukan pemesanan, mengelola keranjang, dan menghitung
total pembayaran menggunakan PHP native.

## Kebutuhan
- XAMPP
- PHP
- Browser
- Git

## Cara Menjalankan
1. Simpan folder project di htdocs.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Akses http://localhost/web1/uts_web1_25012066/

## Fitur
- Daftar dan pencarian menu
- Validasi pemesanan
- Keranjang menggunakan session
- Perhitungan diskon
- Preferensi kategori menggunakan cookie
